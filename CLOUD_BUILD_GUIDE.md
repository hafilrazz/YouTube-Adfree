# Generating APK without Android Studio (Cloud Build)

Since you don't have Android Studio installed, the best way to get your APK is to use **GitHub Actions**. This uses GitHub's own servers to build the app for you.

## 1. Using GitHub Actions (Easiest)

I have already set up a workflow that builds the APK automatically. Follow these steps:

1. **Push your code to GitHub**: If you haven't already, push your project to a GitHub repository.
2. **Create a "Release"**:
   - Go to your repository on GitHub.com.
   - Click on **Releases** on the right sidebar.
   - Click **Create a new release** (or "Draft a new release").
   - Type a version tag (e.g., `v1.0.0`) and a title.
   - Click **Publish release**.
3. **Wait for the build**:
   - Click the **Actions** tab at the top of your GitHub repository.
   - You will see a workflow named "Build Android APK" running.
   - Wait about 3-5 minutes for it to finish (it will show a green checkmark).
4. **Download your APK**:
   - Go back to the **Releases** page.
   - You will now see `app-release-unsigned.apk` under the "Assets" section of your release.
   - Download this file to your Android phone and install it!

## 2. Using Cloud Build Services (Alternatives)

If you cannot use GitHub Actions for some reason, here are other "No-Install" alternatives:

### Expo Application Services (EAS)
Even though this is not an Expo project, you can use services like **EAS** or **Appflow (by Ionic)**.
- **Appflow**: This is the official Capacitor cloud build service. You connect your GitHub repo, and it builds the APK in the cloud. It has a free tier for small projects.

### CodeMagic
- Go to [codemagic.io](https://codemagic.io/).
- Connect your repository.
- It detects Capacitor projects automatically and can build the APK on their servers for free (within their monthly limits).

## Important Note on Installing
Since the APK generated by GitHub Actions is "unsigned", your phone will show a "Blocked by Play Protect" or "Unknown Source" warning.
1. Download the APK to your phone.
2. Open the file.
3. Click **Settings** on the popup and enable "Allow from this source".
4. Click **Install**.
5. If Play Protect warns you, click **Install Anyway**.
